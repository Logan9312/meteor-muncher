# Meteor Muncher

A tiny arcade survival game made for quick play in the browser. Pilot a hungry little UFO, collect stars, and dodge increasingly chaotic meteors.

## Play

- **Move:** Arrow keys or WASD
- **Boost:** Hold Space
- **Restart:** Enter after game over
- **Mobile:** Touch/drag anywhere on the screen

## Run locally

The easiest way:

```bash
npm install
npm start
```

Then open the URL Vite prints, usually <http://localhost:5173>.

You can also just open `index.html` directly in a browser because the game has no backend.

## Why it is easy to run

- No build step required for direct browser play
- No server required unless you want hot reload
- Pure HTML/CSS/JavaScript canvas game
